# React Router v7 Demo

✨ **Modern React 19 + React Router v7 demonstration project with beautiful UI, dark mode, animations and full routing features.**

---

## 🚀 Features

✅ **Modern Tech Stack**

- React 19 with React Compiler
- React Router v7
- Tailwind CSS v4
- Vite for lightning fast development
- Oxlint for linting

✅ **User Interface**

- Glassmorphism sticky navigation bar
- Beautiful light/dark mode toggle with persistence
- Smooth animations & page transitions
- Modern card designs with hover effects
- Staggered entrance animations
- Fully responsive layout for all devices
- Beautiful gradients and depth

✅ **Pages & Routing**

- 🏠 Home page with hero section & feature cards
- 📖 About page with tech stack grid
- 📝 Posts page with interactive post items
- 📨 Contact page with working styled form
- 🚀 Get Started step-by-step guide
- 💡 Learn More documentation page

✅ **Quality of Life**

- Auto detect system preferences for dark mode
- LocalStorage saves your theme choice
- Proper active link highlighting
- Smooth scrolling
- Accessible focus states
- Clean, maintainable component structure

## 📦 Installation

1. Clone or download this project
2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open your browser at the address shown in the terminal (usually `http://localhost:5173` or `http://localhost:5174`)

## 🛠️ Available Commands

| Command           | Description                       |
